Welcome to the official technical documentation for the Text2Voice synthesis engine. Follow the steps below to deploy the application on your local workstation.

Ensure you have Python 3.9+ and FFmpeg installed globally before proceeding.

STEP 01

Clone from GitHub

Pull the latest stable branch of the repository to your local machine.

$ git clone https://github.com/PranjalPanging/text2voice.git $ cd text2voice
STEP 02

Activate Environment

Initialize and activate your virtual environment (venv) to isolate dependencies.

Windows (PowerShell) .\venv\Scripts\Activate.ps1
macOS / Linux source venv/bin/activate
STEP 03

Install requirements.txt

Install all required Python libraries via the pip package manager.

pip install -r requirements.txt
STEP 04

Run the Application

Launch the Flask server. The app will be accessible at http://127.0.0.1:5000.

python app.py
Expected Output: * Running on http://127.0.0.1:5000/
